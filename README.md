# Bookplate

A book rating and reading-log app, like Letterboxd for books.
Search real books, rate them, and keep your own list.

Live demo: [(https://nilmony1952.github.io/bookplate/)](https://nilmony1952.github.io/bookplate/).

## What it does now
- Search any book using the free Open Library API
- Shows real cover images
- Add a book with a 1-5 rating
- Your list is saved in your browser

## Built with
HTML, CSS and JavaScript. No frameworks, no build step.

## Run it
Open `index.html` in a browser. You need an internet connection to search.
